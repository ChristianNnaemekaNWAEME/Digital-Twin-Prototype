# digital-twin-prototype

Integrated prototype connecting three previously separate components
of this endeavor: pattern digitization (matching Exhibit J-7),
cutting-stock optimization (matching Exhibit J-1), and a simulated
equipment-health monitoring layer representing where predictive-
maintenance telemetry would attach to the same pipeline.

See DIGITAL_TWIN_PROTOTYPE.md for full documentation and results.

Requires the cutting-stock-optimizer package (Exhibit J-1) and ezdxf.

Run with: `python digital_twin_pipeline.py`
